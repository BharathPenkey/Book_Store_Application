# Book_Store_Application
This application has a collection of books 

Book Fare – Full Stack Book Store Application

Book Fare is a full stack web application that allows users to explore books, manage a collection, and maintain a personal wishlist. The project focuses on CRUD operations, modern UI design, and a structured full stack architecture.

Features

Core Functionality
  View all books in a responsive layout
  Add new books with image upload
  Edit existing book details
  Delete books with passkey protection
  View detailed information for each book
Wishlist
  Add and remove books from wishlist
  Wishlist stored in localStorage
  Dedicated wishlist page
Search
  Search books by name in real-time

Tech Stack
  Frontend
    React.js
    Tailwind CSS
    Axios
    React Router DOM
  Backend
    Node.js
    Express.js
    MongoDB with Mongoose
  Cloud
    Cloudinary (for image upload) 


API Endpoints

Method	   Endpoint      	Description
GET      	/books	        Get all books
GET     	/books/:id	    Get single book
POST	    /books	        Create a book
PUT	        /books/:id      Update a book
DELETE	    /books/:id	    Delete a book
